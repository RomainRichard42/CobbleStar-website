# Read-only Pokédex assets

Generated by scripts/export-dex-runtime.mjs. These files never change editable
Star templates, publication checks, player Pokémon or the Minecraft mod.

Sources match the installed server:

- Cobblemon Fabric 1.8.0+1.21.1, official models, textures and animations.
- Complete Cobblemon Collection / Myths and Legends compatibility 2.1.0
  (Modrinth qoL4kNxC / Azf9qoT6, SHA1 042b76d7db880f82f135e39cc0d2e0c45ab9a8d0).
- Mega Showdown 1.0+1.8+1.21.1-release-hotfix (Modrinth version we79kHpG).
- Cobblemon Kotlin posers: official GitLab tag 1.8.0, commit
  b33536e8721c9419d664fee15aa9e35cbf1900a8.
- CobbleStar custom forms keep the posers from api/dex-native and the other
  bundled packs described in dex.catalog.json.

index.json retains each provider independently. A read-only preview requires an
exact server species, poser, bone hierarchy, addon ID/version and model/poser hash.
Conflicting providers still block Star editing and publishing; the public viewer
can display the exact provider declared in the server catalogue.

The viewer runs the native stationary/profile pose, bone keyframes (linear or
Catmull-Rom), interpreted Molang and animated texture layers. It is not a Minecraft
client: gameplay, particles, sounds, AI, walking and combat are not simulated.
Models without an idle bone clip retain their native resting pose.
The supplied Genesect expression has a Thai keyboard character on the "1" key;
the viewer normalizes that one leading typo so its head animation can run.

One shared WebGL context paints visible thumbnails at 12 fps; the opened model
runs at 30 fps. Geometry is merged per bone, assets are lazy-loaded and caches
bounded. Animation pauses offscreen, in background tabs, on user request and
with prefers-reduced-motion. Source licenses accompany the generated files.
